# O-08 组件内容配置组

在胶囊几何提交 9065c93 的 CI 40342641447 通过后实施本步骤。

## 实施范围

16 项平铺 Java 字段迁入不可变 ContentSettings：Wi-Fi/移动信号/数字/闪电开关、网络类型位置、
中部数字、双卡、信号位置、堆叠信号、SIM 1/2，以及 Wi-Fi 下隐藏类型、充电中部数字和三个读数标志。
前 11 项维持样式独立，后 5 项维持全局作用域。

偏好和 Bundle 读取共用一组默认值、范围和历史回退规则：

- 胶囊自己的 key 存在时优先，即使保存值等于默认；缺失时继承圆环。
- 网络类型整数优先；只有自己和继承的整数都缺失时才读取退役布尔值。
- 偏好中的退役聚合信号布局继续补开 SIM 1；Bundle 维持原来不补开的区别。
- 裸构造保留 false/0 初值；defaults() 使用偏好默认，不能混为同一个初值。

copy 共享不可变值，equals/hash 纳入整组；单项更新只替换对应成员。
withComponentsFrom 只复制 11 项样式组件，不覆盖接收方的全局标志。
TrioSettings 的 set 方法用于发布前组装，保留原赋值链的值与求值顺序，发布后的快照仍不原地修改。
充电解码、ColorOS 每帧绘制配置和布局求解候选批量构造内容组，避免逐项编辑的中间对象。

Java/Kotlin、预览、充电编辑、两套系统适配器及调试探针均接入新组。
TrioAppearance 对渲染器暴露的已解析字段保持不变；Renderer/Geometry 绘制数学未改。
持久化 key、扁平 Bundle/JSON、Schema VERSION=1 和 61 项逻辑声明均保持不变。
注册表 CONTENT 分组与 record 的 16 个成员逐项核对。

## 对照和回归

修改前保存 9065c93 编译出的真实模型/渲染器/桌面替身，使用同一个探针分别运行旧、新类路径。

84 组规范线值与 336 帧像素 SHA-256 全部相同。
