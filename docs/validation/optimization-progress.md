# 优化实施记录

基线：`695b3a4`（1.0.3）。维护者授权按根目录《优化方案.md》逐项实现、验证，每项单独 commit。

## 最新决策

- 保留 HyperOS 兼容能力及上游提交历史；后续更新逐项评估迁移。
- GitHub Actions 为正式构建/发布入口；新私钥不在开发电脑长期保存。
- 新正式签名采用独立证书。首次须卸载旧版，配置会清除；安装后重新启用 LSPosed 并选择系统界面。
  不使用公开旧密钥为新证书建立 lineage；后续同一新证书的版本可覆盖升级。
- 换签版本发布说明必须醒目提示以上迁移步骤。新版本构建、验证、发布完成后，清理两仓旧 Release，保留源码及 tag。
- 当前手机旧应用数据在验证期间保留；任何真实卸载前先备份并说明。第二台 HyperOS 设备及真实双卡样本缺失时明确记录覆盖限制。
