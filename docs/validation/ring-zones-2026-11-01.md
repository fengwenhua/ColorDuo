# 两种常用圆环布局与整体尺寸

维护者补充的布局为“上部网络／中部电量”和“上部电量／中部网络”，不是把网络放在最底部；同时要求既能用满内部空间，也能将整个圆环及内容一起放大。读取其当前设置为 `5,1|3|7|`、电量字号 45／字重 900、网络字号 44、Wi-Fi 132%、线宽 10、状态栏 120%。原参数保留。

## 修改

- 1.1.25 的适配只在上部候选链包含电量时启用，本次也覆盖上部网络、中部电量。上部网络按中部数字与画布间的剩余空间重新计算位置／比例，网络文字取消旧 23 单位高度预算。
- 中部数字和类型按真实 glyph Path 与内圆边界拟合，而非将字符包围框四个空角都当作墨迹。按字重、字体 generation、尺寸、读数和布局缓存结果，普通重绘不重复构造轮廓。保留 900 字重预留及自定义合成粗体安全余量。
- 中部网络文字根据自己的高度选择中心与字体大小，不再先缩小到旧的矩形弦长，再继承 Wi-Fi 的整体缩放。5GA 后缀的小字比例也参与轮廓测量。字体不拉伸，长标签仍尊重真实物理边界。
- ColorOS 圆环允许 `glyph_scale_pct` 到 150，胶囊／矩形仍为 100。100% 以上放大 ImageView 及必要的电池容器占位，按父行剩余空间钳制，Drawable intrinsic 同步；绘制比例仍最多 1，避免重复放大和越出画布。该选项只在支持的 ColorOS 设备显示扩大范围，HyperOS 旧路径不改变。
- 配置回退／样式变化会恢复图像和容器最新 OEM 尺寸，临时样式更新前只还原参数而不触发中间布局。卡片预览保持适配，真实状态栏展示整体放大。

## 检查计划

新增 RingViewport 的原始／125%／150%、行高／窄窗口上限测试，以及两种布局的实际字号、组件分离、点击归属、字形不碰圆环和方案切换缓存回归。绘图替身补齐带字距的 glyph path，与已有 Canvas 文字绘制一致。

本地完整门禁通过：224 项 JUnit（app 60、render 107、host 57）、22 项 Python、release lint、R8 构建、签名协议集成及 observer 缺席检查。

同签名候选及 Find N5 原生／实际状态栏尺寸与恢复尚在进行；不把尚未完成的人工或设备检查记为通过。当前公开稳定版仍为 1.1.25。
