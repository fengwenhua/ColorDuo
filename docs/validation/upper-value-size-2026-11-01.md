# 上部数字放大与中部让位选项

## 需求与边界

维护者指出 1.1.24 的上部字号上限约为 30，希望继续增大；随后选择“数字优先，中部必要时移动或缩小”，并要求把它做成由用户选择的设置项。维护者同时授权：CI、测试通过后直接发版，并在公开发布后回复 issue #8 请反馈者复测。

此前按信号点的占位高度限制文字，未用满顶部真实空间。保留该占位并仅限制滑块虽然消除了无效区间，但过于保守。本次新增独立全局开关 `ring_value_priority`，缺省为 false，通过 Schema、偏好读取、Bundle、ConfigPacket、copy、单键更新及相等性比较传递；不修改原有 ContentSettings 记录或充电布局编码格式，充电／快充布局继承此选项。

## 布局

- 「组件 → 电量数字 → 上部数字放大方式」提供“保持中部布局”和“为数字让位”。仅圆环显示，缺省保持；选项实时保存并发布，胶囊与矩形不参与此布局。
- 保持模式利用可见画布与中部组件之间的完整空间，必要时在上部范围内调整数字锚点，中部位置和比例保持不变。
- 让位模式以数字为优先，常规字体可使用完整 16–56；在宿主范围内放置数字，并为中部保留可读空间。中部按所有已放置候选组件的包围范围，向下移动并必要时统一缩放，避开数字与下部信号点；不扩张原有径向包围范围，不改变圆环宿主测量尺寸。
- 几何计算使用已配置的候选链，与实时 Wi-Fi、移动网络和充电是否可用分离，避免状态切换造成反复布局。字号、字体、模式、其他组件尺寸与布局变化会刷新缓存；普通绘制复用缓存。
- 仍使用实际文字墨迹计算环线开口；数字加粗保留 1.1.24 的稳定 em。编辑区域和高亮同时跟随上、下分界及放大的数字宽度，画布以外继续不响应点击。

## 本地验证

新增五项生产渲染回归：保持模式可用范围与中部不动、让位时 30／36／44／56 全区间有效、Wi-Fi 100／134／160% 与线宽 4／8／16 下数字／中部／信号点的像素间距和实际点击归属、网络／充电变化的缓存稳定与模式恢复、配置复制／传输／单键更新。数字墨迹、宿主边缘、环线圆头间距及编辑高亮同步检查。

旧“中部范围总比上部更大”的测试前提不再适用：上部现在能使用画布宽度与自适应开口，中部仍受内圆弦长限制。该测试改为分别验证各区有效范围及已保存字号不被改写。点击越界的回归保持不变，修正实现的底部边界以继续通过。

生产 Canvas 审阅图仅保存在忽略目录 `.local/upper-value-size-2026-11-01/images/`，包含保持／让位的 30、44、56 对照。217 项 JUnit（release app 58／render 102／host 57）、22 项 Python、Lint、Release 构建、签名集成及 Observer 包装检查通过；桌面使用替代字体，不能替代 Find N5 的真实效果确认。
