# 圆环开口不跟随上部组件尺寸：issue #8

## 现象与原因

[issue #8](https://github.com/fengwenhua/ColorDuo/issues/8) 的三张截图显示，上部放数字／闪电时，环线端点离组件较远；较宽的时间正好能填满开口。要求同时适配数字字号／字重、闪电大小。

源码确认原 Ring 使用固定参考开口，没有读取当前组件实际绘制边界。该参考预算用于文字拟合与 Wi-Fi／信号点阵布局，但也被直接用于绘制所有组件的缺口。字体或闪电变小时，缺口仍保持原宽度。

## 修复范围

- 复用真实绘制的文字拟合、字体和字重，读取实际墨迹边界；复用闪电 Path 的边界和实际拟合／用户缩放。网络类型的小字后缀按真实缩放合并边界。
- 在上下两端计算与墨迹最后相交的圆弧角度，包含环线圆头半径与抗锯齿余量，避免只按字号或字符数估计。上下开口分别计算，电量进度仍沿实际可见弧线分配。
- 预览和状态栏共用计算，编辑点击同样使用实际开口。参考拟合预算、Wi-Fi 和点阵的既有形状保留，不改存储配置或宿主尺寸。
- 桌面 Paint 替身补齐真实墨迹宽度及负字距，避免测试测量使用未跟踪字距的整串宽度；Path 替身补齐 Android computeBounds 协议。替身只用于主机渲染测试，不打入 APK。

## 验证

新增生产 Canvas 像素回归：数字字号／字重和线宽、1／2／3 位电量、重复实时字重切换、闪电 60%–160%、下部文字／空区闭合、实际弧线点击，以及时间／网络类型／Wi-Fi 回退。原图、渲染比较与负向对照仅存忽略目录 `.local/issue8/`。

完整 JUnit 207 项（Release app 58／render 92／host 57）、Python 22 项、Lint、Release 构建、签名集成与 Observer 不打包检查通过。Lint 为 0 errors、34 warnings、1 hint。将同一绘制路径退回固定参考开口作负向对照，7 项新增回归全部失败；修复实现全部通过。旧／新比较图包含 64、闪电和时间，端点能随实际墨迹收拢。

同签名真机验收结果待补充；当前公开稳定版仍为 1.1.21。
