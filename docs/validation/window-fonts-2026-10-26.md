# 窗口与大字体验收

设备：Find N5（PKH110），ColorOS 16 / SystemUI 16.99.12。

外屏 1140×2616，字体 1.0/1.3/1.5 的首页与关于页各采集一次。自动检查导航按钮均在有效屏幕内，
手工查看截图发现 1.5 倍下固定正方形状态卡会遮挡版本和统计数字。
修复为：窄窗口/大字体采用内容驱动高度，激活信息占整行，统计另起一行；
正常宽度保持原布局，装饰徽章绘制在文字背后。

修复包 Lint/debug 构建及 304 项 Android 检查通过；外屏三档重测完成，1.5 倍截图的版本与统计已完整显示。
每轮检查均恢复原字体倍率 1.0，未更改用户圆环/胶囊配置。
内屏 2248×2480 也完成三档字体的首页/关于页截图与导航检查，1.5 倍下版本及统计完整。
左右分屏由维护者实际操作验收：1.5 倍字体下关于页完整，组件尺寸弹层可滚动、可关闭，无窗口越界。
最后保留分屏取证，窗口日志记录模块 Rect(0,0–1111,2480)，截图同时显示 ColorDuo 和系统设置；
字体已恢复 1.0。中途另两张字体参考图取证时已回全屏，不计为分屏截图。
本轮未启用 TalkBack 做语音朗读验收，也未把逻辑单测或导航边界检查冒充视觉验收。

可复用入口：`scripts/verify-ui.py --serial DEVICE --panel outer|inner|split --output .local/UNIQUE_PATH`。
报告与截图只存本机忽略目录；脚本只在显式运行时改变字体，并以 finally 恢复原设置。
