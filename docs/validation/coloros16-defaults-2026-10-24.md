# 1.0.2 首次安装默认配置

用户授权读取 Find N5 当前圆环、胶囊配置，作为1.0.2首次安装的默认值。
通过 ADB 读取应用偏好，只迁入22项可移植的布局与外观选项；未带入传输快照、revision、设备身份或文件路径。
没有单独设置的字号、颜色等选项沿用当前代码默认值，保持与采集时手机的解析结果一致。

| 配置 | 圆环 | 胶囊 |
| --- | --- | --- |
| 上部优先级 | 网络类型、Wi-Fi | 网络类型、Wi-Fi |
| 中部优先级 | 电量数字 | 闪电、电量数字 |
| 下部 | SIM1信号 | SIM1信号 |
| 左部 | 空 | 时间 |
| 普通充电 | 继承基础布局，中部数字 | 独立布局，中部数字、闪电 |
| 快充 | 独立布局，中部闪电、数字 | 继承基础布局，中部闪电、数字 |

默认先选择圆环，启用Wi-Fi、移动信号、电量与SIM1组件，SIM2关闭；网络类型放入内部区域。
打开「连接Wi-Fi时隐藏网络类型」，环外顺序保留手机存储的`1,3,2`，导航样式保留存储值2。

`FirstRunDefaults.install()` 在应用首次启动、框架同步前初始化。仅当整个偏好文件为空时写入，
只要已有任何设置就全部保留，避免覆盖升级或再次启动时修改用户布局。
此初始化不修改渲染器在缺少配置时使用的回退值。

新增10项真实 Android 检查覆盖首次初始化、两种样式的精确布局、普通/快充中部选择、时钟、
重复启动、已禁用组件、显式空布局，以及只保存了关闭总开关的最小配置。

1.0.2 debug/release、R8、release lint vital 构建通过；Android instrumentation共250项通过，
包括上述10项首次安装检查。已有用户的真实偏好只在测试中临时改变后恢复，保留传输revision递增。
