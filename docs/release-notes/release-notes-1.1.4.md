# 1.1.4

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）必须先卸载，再安装 1.1.4。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版：直接覆盖升级即可，保留配置，无需卸载。**

## 功能修复

- **网络类型残留**：修复 Wi-Fi 和移动数据都关闭后，圆环／胶囊仍显示 5G 等网络类型的问题；关闭数据时同步隐藏环内、环外的制式文字，重新启用移动数据后自动恢复。蜂窝信号强度继续独立显示。

---

**安装**：1.1.0 及以上新签名正式版可覆盖安装，设置保留。低于 1.1.0（不包含 1.1.0）的版本须卸载重装；旧测试签名调试包也须卸载后安装正式包。
