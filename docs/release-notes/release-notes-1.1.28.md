# 1.1.28

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）须先卸载重装。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版可直接覆盖升级，保留配置。**

## 网络图标交接

- 修复开关 Wi-Fi／移动数据、Wi-Fi 重新连接时，圆环／胶囊仍在，但左侧短暂出现原生网络图标的问题。
- 识别 ColorOS 普通 Wi-Fi 在网络可用性验证前后的相同图案，连接阶段及时在组件中显示；保留系统的网络状态无障碍描述。无法等价表示的其他警告图案继续保留原生提示。
- 网络图标隐藏与新帧的实际像素准备在同次绘制前完成；若图标位置还需布局，则等布局完成后一起显示，避免先露出原生图标再替换。
- 下拉面板等某个网络视图移除时，仅释放它关联的接管，不再影响其他状态栏区域。关闭模块、移除宿主或准备新帧失败时仍恢复原生显示。

## 整体图标大小入口

- 修复圆环的整体尺寸滑块未出现在「组件 → 外观」的问题。现在「整体图标大小」紧接「三合一样式」显示；ColorOS 圆环支持 60%–150%，胶囊／矩形保留原有范围，同一设置实时生效。ColorOS 圆环 100% 以上受当前状态栏可用高度限制。
