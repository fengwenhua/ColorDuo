# 1.1.6

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）必须先卸载，再安装 1.1.6。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版：直接覆盖升级即可，保留配置，无需卸载。**

## 功能修复

- **继续修复 [issue #4](https://github.com/fengwenhua/ColorDuo/issues/4) 中的“充电功率显示为 0”**：修正 ColorOS / OPlus 电池路径的电流单位换算，解决有充电电流时功率被缩小 1000 倍、最终显示成 `0.0W` 的问题。继续采样实时电池电流和电池电压，显示电池侧功率估算。
- 保留真实零电流的 `0.0W`，无法读取时不伪造零值；温度显示和 HyperOS 的微安换算保持原有行为。

## 内部维护

- 完善配置分组和测试：组件内容、胶囊几何使用不可变配置组，保留旧配置迁移、圆环／胶囊独立设置和局部更新。
- 完善桌面测试入口，以及发布草稿恢复和说明换行校验。

---

**安装**：1.1.0 及以上新签名正式版可覆盖安装，设置保留。低于 1.1.0（不包含 1.1.0）的版本须卸载重装；旧测试签名调试包也须卸载后安装正式包。
