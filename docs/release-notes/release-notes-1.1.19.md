# 1.1.19

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）须先卸载重装。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版可直接覆盖升级，保留配置。**

## 功能修复

- **Wi-Fi 原生图标重复出现**：修复开关 Wi-Fi 后，圆环／胶囊左侧原生 Wi-Fi 图标延迟消失，以及系统后续刷新时再次出现的问题。同步系统实际应用的图标可见性，已完成接管时立即保持隐藏，关闭三合一后恢复原生显示。
- **包含此前的动画与类型修复**：保留调高状态栏后下拉／收回的平滑过渡，以及信号视图重新绑定后的 Wi-Fi／5G 类型恢复修复。
