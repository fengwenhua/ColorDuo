# 1.1.17

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）须先卸载重装。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版可直接覆盖升级，保留配置。**

## 功能修复

- **Wi-Fi／网络类型恢复**：修复信号视图重新绑定时，5G 等类型缓存可能被清空后不恢复的问题。切换网络和恢复界面时核对系统当前类型，避免漏一次更新后持续留空；圆环与胶囊同时生效。
- **网络状态判断**：保持双关时不显示网络类型、连接 Wi-Fi 时按已有设置隐藏类型；当前系统不提供类型或出现未知提示时交还系统，不沿用过期的 5G。
