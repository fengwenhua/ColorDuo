# 1.1.0

> **签名迁移必读：请先卸载旧版本 ColorDuo，再安装此版本。卸载会清除全部应用配置，请提前记录自己的布局。安装后需在 LSPosed 重新启用 ColorDuo，勾选「系统界面」作用域，并重载系统界面。后续使用新签名的正式版本可正常覆盖更新。**

## 功能添加

- **兼容性报告**：在「关于 → 复制兼容性报告」查看设备、系统版本与适配状态；不包含网络名称、通知或原始日志，由你决定是否分享。

## 功能修复

- **插电后立即开合**：充电提示出现时立刻展开或合上手机，保留已显示的圆环／胶囊，避免短暂闪回原生图标。已在 Find N5 复测。
- **设置实时生效**：拖动尺寸等滑块时预览即时更新，合并保存连续变化；松手、退出页面和服务重连时同步最终值。
- **关于页大字体**：窄窗口使用大字体时，激活信息和统计卡片随内容增高，版本号与统计数字不再被截断。

- **外屏设置弹层**：按当前窗口高度调整可用空间，改善折叠和分屏下的显示；预览状态箭头扩大点击区域并适配从右向左的布局。
- **检查更新**：「关于 → 检查更新」会验证更新包来源、完整性和版本，验证失败时拒绝安装，可打开官方发布页处理。

## 功能变更

- **正式版签名**：采用新的独立签名。此版本首次迁移需要卸载旧版，完成后可继续正常更新。
- **正式版运行**：默认关闭完整观察诊断和频繁状态日志，保留必要的故障与恢复信息；需要排查时可开启日志或使用专用诊断构建。

---

**安装**：先卸载旧版本，再安装此版本；卸载会清除配置。安装后重新在 LSPosed 启用模块、选择系统界面并重载。
