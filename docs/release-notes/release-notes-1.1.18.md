# 1.1.18

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）须先卸载重装。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版可直接覆盖升级，保留配置。**

## 功能修复

- **状态栏下拉与收回**：调高状态栏后，过渡动画中的时钟、通知与右侧图标同步使用自定义尺寸，修复短暂变回原始大小再放大的闪跳，保留系统面板原有过渡动画。
- **下拉头部显示**：面板顶部网络、电量和运营商区域同步缩放，保持右侧贴边；恢复系统高度或关闭总开关时还原原生显示。
- **Wi-Fi／网络类型恢复**：修复信号视图重新绑定时，5G 等类型缓存可能被清空后不恢复的问题；核对系统当前类型，系统清空时不残留旧 5G。圆环与胶囊均生效。
