# 1.1.22

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）须先卸载重装。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版可直接覆盖升级，保留配置。**

## 功能修复

- **圆环开口跟随组件大小**：修复上部放置电量数字或充电闪电时，环线仍预留过宽空间的问题。开口按实际绘制的数字、时间、网络类型及闪电边界调整，并为圆头环线保留必要间距。
- **实时尺寸适配**：数字字号、字重、闪电大小和电量位数变化后同步更新，预览与状态栏共用绘制路径；下部放置文字／闪电时同样生效，Wi-Fi 与信号点阵保持原有布局。
- **编辑点击一致**：缩小开口后新增的环线仍能正确点击，不会沿用旧开口的点击范围。

对应问题：[issue #8](https://github.com/fengwenhua/ColorDuo/issues/8)。
