# 1.1.23

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）须先卸载重装。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版可直接覆盖升级，保留配置。**

## 功能修复

- **电量字号的有效范围**：圆环数字的字号上限根据摆放位置、字体、字重及线宽计算，并核对 0–100 的读数，避免滑块继续增大、数字却被自动缩小抵消。移到中部后可使用更大的字号；已有配置保留，绘制仍会防止内容越界。
- **字重调节有效档位**：电量数字按当前字体的真实轮廓合并相同效果的字重。修复字体最高只支持 700、界面却仍提供没有变化的 800／900 的情况；自定义字体更换后重新识别，预览和状态栏继续共用字体及绘制设置。
- 包含尚未公开发布的 1.1.22 修复：圆环上下开口跟随数字、文字和闪电的实际边界，并同步编辑点击范围，对应 [issue #8](https://github.com/fengwenhua/ColorDuo/issues/8)。
