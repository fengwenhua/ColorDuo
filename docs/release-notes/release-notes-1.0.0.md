# 1.0.0

## 功能添加

- **ColorOS 16**：适配 Find N5 的圆环、胶囊和网络融合。启用 ColorDuo 后选择系统界面作用域，重启系统界面即可配置外观。
- **胶囊和环外组件**：在组件设置中调整时钟、字体、网络类型、信号条及温度和功率读数，支持 Find N5 内外屏布局。

## 功能修复

- **网络类型**：打开「连接 Wi-Fi 时隐藏网络类型」并为同一区域配置 Wi-Fi 后，连接时显示 Wi-Fi，断开后由蜂窝类型接替。
- **状态栏间距**：修复 Wi-Fi 与 5G 切换时原生图标残留的空位和抽动；移动信号融合后，同时隐藏原生上下行三角箭头。
- **快捷编辑预览**：修改当前样式的组件与排序后，小卡片立即更新，不再需要来回切换圆环和胶囊。

## 功能变更

- **独立应用**：项目更名为 ColorDuo，检查更新与下载指向 ColorDuo 仓库；应用使用独立包名，与 HyperDuo 分开保存配置。

---

**安装**：从 HyperDuo 切换时，先停用旧模块的系统界面作用域，再安装并启用 ColorDuo。旧设置不会自动迁移。
