# 1.1.12

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）必须先卸载，再安装 1.1.12。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版：直接覆盖升级即可，保留配置，无需卸载。**

## 状态栏高度

- 首页总开关下新增「状态栏高度」，100% 跟随系统，可增加至 150%，支持一键恢复。
- 在已适配的 ColorOS 上，桌面及普通应用的顶部状态栏、窗口预留空间和圆环／胶囊宿主尺寸联动调整。
- 内外屏以各自系统默认高度计算；关闭总开关后恢复系统高度。保留圆环／胶囊与各充电场景的既有配置。
