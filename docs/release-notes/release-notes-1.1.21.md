# 1.1.21

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）须先卸载重装。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版可直接覆盖升级，保留配置。**

## 功能修复

- **修复系统外置电量与圆环／胶囊冲突**：系统「电量百分比」选择「在电池外显示」时，ColorDuo 按自己的布局显示内部电量，不再清空内部数字、将百分比留在图标右侧。
- **恢复原生显示**：仅在替代图标成功绘制且布局拥有电量组件后隐藏重复的系统数字；关闭模块、移除电量组件、视图解绑或绘制失败时恢复系统原有状态。运行中切换系统百分比位置也会更新恢复状态。

对应问题：[issue #7](https://github.com/fengwenhua/ColorDuo/issues/7)。
