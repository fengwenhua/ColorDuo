# 1.1.20

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）须先卸载重装。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版可直接覆盖升级，保留配置。**

## 功能修复

- **离开 Wi-Fi 后恢复 5G／4G**：修复 Wi-Fi 开关保持开启、连接断开后，圆环／胶囊上的网络类型可能持续留空，需要手动开关流量才能恢复的问题。同步默认数据 SIM 的真实移动数据开关，避免过期的“流量关闭”缓存隐藏网络类型。
- **SIM 初始化与切换恢复**：SIM 暂未就绪时不误判为用户关闭流量；SIM 就绪或默认数据卡切换后重新绑定状态源，拒绝旧订阅的迟到回调。真正关闭移动数据时仍隐藏蜂窝网络类型。
