# 1.1.5

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）必须先卸载，再安装 1.1.5。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版：直接覆盖升级即可，保留配置，无需卸载。**

## 功能修复

- **修复 [issue #4：启用读数组后，充电会导致聚合失效](https://github.com/fengwenhua/ColorDuo/issues/4)**：修复开启充电功率后，插入充电器或读数宽度变化时圆环／胶囊可能消失、回退为原生图标的问题。尺寸变更期间保留已绘制的三合一，等待实际布局完成；空间不足时让可选环外读数退让，不再把电池宿主标记为永久失败。

## 验证

- 已在 Find N5 / ColorOS 16 验证圆环、胶囊开启充电功率后的 USB 拔插与内外屏折叠切换。
- 115 项 JUnit 测试、Lint、release 构建及云端签名校验通过。

---

**安装**：1.1.0 及以上新签名正式版可覆盖安装，设置保留。低于 1.1.0（不包含 1.1.0）的版本须卸载重装；旧测试签名调试包也须卸载后安装正式包。
