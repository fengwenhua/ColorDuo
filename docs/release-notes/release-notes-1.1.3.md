# 1.1.3

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）必须先卸载，再安装 1.1.3。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版：直接覆盖升级即可，保留配置，无需卸载。**

## 功能修复

- **Wi-Fi 下的信号聚合**：修复 ColorOS 连接 Wi-Fi 后关闭移动数据，圆环／胶囊左侧重新出现原生移动信号的问题；移动数据关闭时仍可聚合正常在网的信号，无服务或实际网络告警时继续保留原生提示。（[issue #3](https://github.com/fengwenhua/ColorDuo/issues/3)）

---

**安装**：1.1.0 及以上新签名正式版可覆盖安装，设置保留。低于 1.1.0（不包含 1.1.0）的版本须卸载重装；旧测试签名调试包也须卸载后安装正式包。
