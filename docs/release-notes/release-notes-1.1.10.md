# 1.1.10

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）必须先卸载，再安装 1.1.10。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版：直接覆盖升级即可，保留配置，无需卸载。**

## VPN 高亮

- VPN 开启时，圆环／胶囊中的 Wi-Fi 图标与 5G 等网络类型文字高亮；四个信号点及环外信号条保留原色。
- 在「组件 → VPN」选择颜色，默认蓝色；VPN 断开后恢复原色，无需下拉状态栏触发。
- ColorOS 的对应状态栏实际绘制高亮后，隐藏重复的原生 VPN 图标与下拉面板右上角 VPN 标签；没有高亮内容或关闭三合一时交还系统显示。
- 下拉面板中的相机、麦克风、定位图标和其他安全模式提示保留；只有 VPN 标签的空背景一并移除。
