# 1.1.7

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）必须先卸载，再安装 1.1.7。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版：直接覆盖升级即可，保留配置，无需卸载。**

## 功能修复

- 修复 ColorOS 充满后仍显示温度和充电功率的问题：以系统实际充电状态决定读数显隐，插着充电线不再等同于正在充电。
- 功率、温度均开启且勾选“温度仅充电时显示”时，两项成组出现或消失；充满、暂停充电、拔线或读数不完整时整组隐藏，恢复充电且读数完整后一起恢复。
- 未勾选“温度仅充电时显示”时保留独立温度显示；单独开启功率或温度的行为保持独立。
- 保留 1.1.6 对 [issue #4](https://github.com/fengwenhua/ColorDuo/issues/4) 的电流单位换算修复，以及圆环／胶囊的稳定接管。

---

**安装**：1.1.0 及以上新签名正式版可覆盖安装，设置保留。低于 1.1.0（不包含 1.1.0）的版本须卸载重装；旧测试签名调试包也须卸载后安装正式包。
