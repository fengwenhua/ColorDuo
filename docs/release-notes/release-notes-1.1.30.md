## 移动信号闪现

- 继续修复 Wi-Fi 关闭时重新开启移动数据，原生信号条短暂出现、圆环／胶囊内信号点暂时消失的问题。
- 依据系统实际绘制的普通信号资源判断接管能力，避免把网络验证期间不变的无线信号误认为不可绘制；保留原生网络状态的无障碍描述。无服务、特殊 SIM、未知警告等不能等价表示的图案继续留给系统。
- 已接管的移动信号不再仅因原生视图暂时处于溢出／隐藏排版状态而退出；新宿主、系统隐藏策略、断开宿主和真正不支持的读数仍保留原生处理。

## 双电芯功率补偿（#11）

- 「组件 → 读数组」新增「双电芯功率补偿 ×2」，默认关闭，圆环、胶囊及预览实时生效。
- 仅适用于上报单颗电芯功率的设备；已经上报整组功率的设备请保持关闭。该选项只将电池侧估算功率乘二，不改变温度、充满隐藏行为或两平台各自的电流单位换算。

## 默认上网卡选择（#10，部分改善）

- ColorOS 的聚合信号和网络类型优先跟随系统当前默认上网卡，不再因两个同级移动信号条目而直接放弃，亦不根据条目顺序选择卡 1。两张卡数据开关都开启时，切换上网卡仍会触发刷新。
- 未被聚合表示的另一张卡继续显示原生信号。当前仍不支持把两张卡的信号同时合并进同一个圆环／胶囊；默认上网卡切换已通过模拟测试，尚待双卡实机验收。
