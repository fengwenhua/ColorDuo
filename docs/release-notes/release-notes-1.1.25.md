# 1.1.25

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）须先卸载重装。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版可直接覆盖升级，保留配置。**

## 圆环开口与电量数字

- **修复 [issue #8](https://github.com/fengwenhua/ColorDuo/issues/8)**：上、下部环线开口跟随数字、文字和充电闪电的实际边界，调整字号、字重或闪电大小后同步更新；缩小后的环线点击范围也同步适配。
- **上部数字可以更大**：使用实际可用空间，解除先前把数字限制在信号点占位高度内的保守限制。可用字号随字体、线宽、组件布局和放大方式计算，不再提供已被自动缩小抵消的无效区间。
- **新增「组件 → 电量数字 → 上部数字放大方式」**，实时生效：默认「保持中部布局」，利用剩余空间放大数字；选择「为数字让位」后，中部 Wi-Fi／5G 等组件可自动移动或缩小，为数字腾出空间，常规字体可使用到 56。字体或布局特别拥挤时仍保留边界保护。
- **加粗时尺寸稳定**：为粗体预留空间，避免提高字重后自动缩小字号抵消效果；合并字体中绘制完全相同的字重档位，支持 100–900 的字体继续提供完整范围。
- **状态与编辑一致**：预留所有已放置候选组件的空间，避免 Wi-Fi／5G 或充电状态切换时反复挪动；预览、状态栏、编辑点击和高亮区域共用新布局。

包含此前 1.1.22–1.1.24 测试候选的修复；这些候选没有单独公开发布。胶囊和矩形保持各自布局。
