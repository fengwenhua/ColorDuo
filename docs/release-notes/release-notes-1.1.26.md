> **1.1.0 及以上新签名正式版可直接覆盖升级，保留配置。**

## 圆环放大

- **两种常用布局均适配**：网络类型／Wi-Fi 在上、电量在中，以及电量在上、网络类型／Wi-Fi 在中。上部网络按实际可用空间放置，不再把 5G 字号压缩到旧的小条带里。
- **中部读数使用真实字形拟合**：依据数字、字母的实际轮廓避开圆环，减少矩形包围框空白造成的过度缩小。中部网络文字不再继承较高的 Wi-Fi 图案的缩放和中心，网络类型在圆环中的字号可设到 64；长标签仍按实际空间适配。
- **整个圆环也能放大**：ColorOS 圆环的「组件 → 外观 → 整体图标大小」支持到 150%。100% 以上扩大状态栏实际占位，圆环和内部组件一起变大，受当前行的可用高度限制；保持原有 60%–100% 比例调整，胶囊／矩形及其他系统保留原范围。
- **恢复与边界**：恢复 100%、关闭模块或切换样式时恢复系统原尺寸；保留充电重绑定期间的显示接管，编辑点击与预览继续共用内部几何。卡片中的图案预览按固定画布适配，状态栏实时呈现实际整体大小。
