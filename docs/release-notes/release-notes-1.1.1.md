# 1.1.1

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）必须先卸载，再安装 1.1.1。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **已安装 1.1.0 新签名正式版：直接覆盖升级即可，保留配置，无需卸载。**

## 功能修复

- 修复 ColorOS 接电但暂停充电、或已充满时，圆环／胶囊右侧再次出现原生闪电及占位的问题。
  保持按真实状态选择普通充电、快充和未充电布局；关闭三合一或模块退出接管时正常恢复原生图标。

## 安装

从 **1.1.0 新签名正式版**可直接覆盖升级，配置保留。
版本号 **< 1.1.0** 的旧版必须卸载重装；**1.1.0 不在此范围内**。
使用旧测试签名的调试包与正式签名不同，也需先卸载再安装；这一点不能仅凭调试包的版本号判断。
