# 1.1.2

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）必须先卸载，再安装 1.1.2。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版：直接覆盖升级即可，保留配置，无需卸载。**

## 功能修复

- **圆环预览点击区域**：修复「组件」绘制预览中，描边较粗时圆环底边少量可见区域无法点击的问题；底部编辑区域现在覆盖完整底边。

---

**安装**：1.1.0 及以上新签名正式版可覆盖安装，设置保留。低于 1.1.0（不包含 1.1.0）的版本须卸载重装；旧测试签名调试包也须卸载后安装正式包。
