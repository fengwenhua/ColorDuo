# 1.1.24

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）须先卸载重装。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版可直接覆盖升级，保留配置。**

## 功能修复

- **圆环电量数字加粗不再被缩小抵消**：文字适配先为粗体预留空间，再绘制所选字重，避免提高字重时反过来缩小字号。特殊自定义字体保留越界保护。
- **电量字号的有效范围**：按圆环摆放位置、字体和线宽计算有效字号上限，并检查 0–100 的读数，避免提供已被自动适配抵消的字号档位。已有配置保留，移到中部后可用更大的字号。
- **字重档位跟随字体**：数字按当前字体的真实轮廓合并效果完全相同的相邻档位；支持 100–900 的字体继续提供完整范围，更换字体后重新识别。
- 包含尚未公开发布的 1.1.22 修复：圆环上下开口跟随文字／闪电的实际边界，并同步编辑点击范围，对应 [issue #8](https://github.com/fengwenhua/ColorDuo/issues/8)。1.1.23 是本轮中间测试候选，未正式发布。
