# 1.1.9

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）必须先卸载，再安装 1.1.9。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版：直接覆盖升级即可，保留配置，无需卸载。**

## VPN 高亮

- VPN 开启时，仅 Wi-Fi 图标与 5G 等网络类型文字高亮，四个信号点及环外信号条保留原色。圆环与胶囊均适用。
- 「组件 → VPN」可自选高亮颜色，默认蓝色；VPN 断开后恢复原色，无需下拉状态栏触发。
- ColorOS 对应状态栏已实际画出 VPN 高亮后，隐藏该行重复的原生 VPN 标识；关闭三合一或该行没有可高亮内容时交还系统显示。
- 保留系统 VPN 的实际状态和通知，已有的原生图标隐藏设置在停用模块后保留。
