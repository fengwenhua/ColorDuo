# 1.1.15

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）必须先卸载，再安装 1.1.15。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版：直接覆盖升级即可，保留配置，无需卸载。**

## 状态栏高度

- 首页总开关下新增「状态栏高度」，100% 跟随系统，可增加至 150%，支持一键恢复。
- 在已适配的 ColorOS 上，桌面及普通应用的顶部状态栏、窗口预留空间和整行内容联动调整；时钟、通知、网络及圆环／胶囊统一放大，以摄像头中心对齐。
- 内外屏以各自系统默认高度计算；关闭总开关后恢复系统高度。保留圆环／胶囊与各充电场景的既有配置。

- 修复恢复系统高度时残留旧留白导致图标挤向顶部的问题；恢复时同时还原内容区位置、尺寸和缩放。

- 修复右侧随内容宽度反复收缩直至图标消失的问题，右侧以固定可用区域计算并保留原生内部动画。
- 修复下拉收回后短暂恢复小图标再放大的抖动，绘制前校准尺寸，不在普通布局刷新中重置缩放。

## 胶囊宽度与内部间距

- 「组件 → 外观」选择胶囊后，在样式选择下直接显示「胶囊宽度」，拖动实时更新预览和状态栏；布局页保留同一个设置入口。
- 左侧内容靠左、右侧内容靠右，两端跟随胶囊宽度变化。时间与 100 电量等内容拥挤时，统一等比缩小内部内容并保留间距，避免贴合或重叠。
- 加宽只延长胶囊的直线段，高度和圆角不变；沿用原有宽度配置，不覆盖已有布局与充电场景。
