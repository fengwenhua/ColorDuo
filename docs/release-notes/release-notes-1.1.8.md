# 1.1.8

> **升级必读：低于 1.1.0 的旧版本（不包含 1.1.0）必须先卸载，再安装 1.1.8。卸载会清除配置，请提前记录布局；安装后在 LSPosed 重新启用 ColorDuo、勾选「系统界面」并重载系统界面。**
>
> **1.1.0 及以上新签名正式版：直接覆盖升级即可，保留配置，无需卸载。**

## 新增功能

- VPN 开启时，圆环／胶囊绘制的 Wi-Fi、移动信号和网络类型使用高亮色，默认蓝色；VPN 断开后恢复原色。
- 「组件」新增 VPN 设置，可选择高亮颜色或恢复默认蓝色；圆环与胶囊共用该颜色。
- VPN 状态独立监听，无需下拉状态栏；电池、电量数字、时钟及充电读数保留各自颜色。
