# 1.0.3

## 功能修复

- **插入充电器时的图标**：修复插电瞬间圆环／胶囊短暂退回原生图标、数秒后才恢复的问题。系统显示充电提示时继续保留三合一图标，胶囊尺寸和时间也保持稳定。
- **预览状态列表**：首页「预览状态」在外屏显示不全时，增加滑动提示和可点击箭头，可查看后面的「危险／无 Wi-Fi」并返回；全部状态能显示时不添加提示。

---

**安装**：覆盖安装即可，设置保留；更新后重载系统界面以加载新代码。

**验证**：Find N5 / ColorOS 16；283 项 Android 检查及 82 项纯 Java 检查通过，圆环、胶囊的实际 USB 插拔和外屏箭头操作均已确认。
