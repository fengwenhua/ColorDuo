# 1.0.2

## 功能添加

- **首次安装默认布局**：首次打开即使用 Find N5 实测的圆环／胶囊配置，Wi-Fi 与网络类型自动让位，并分别保存普通充电与快充布局。覆盖升级保留已有设置。

- **独立充电布局**：在「预览状态 → 充电／快充」分别编辑组件布局，可设置普通充电中部显示数字、快充中部显示闪电。圆环与胶囊各自保存，字号、颜色等外观共用；尚未单独编辑的状态沿用原有布局。

## 功能修复

- **充电闪电与间距**：修复 ColorOS 充电时圆环或胶囊旁重复出现原生闪电的问题，同时移除它的额外占位。模块实际绘制充电帧后才接管，停用或绘制失败时恢复系统图标。
- **充电预览与保存**：普通充电和快充的组件编辑不再互相覆盖，快捷编辑卡片、预览与状态栏使用一致的配置。

---

**安装**：覆盖安装即可，设置保留；更新后重载系统界面以加载新代码。

**验证**：Find N5 / ColorOS 16；250 项 Android 检查和 82 项纯 Java 检查通过。普通充电接管与占位释放已通过日志确认，用户已确认独立布局编辑及真实快充显示正常。
